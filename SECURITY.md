# Security and the record

This repository holds a live forecast record: each quarter's estimate is locked as a GitHub release before General Dynamics reports. If you find a way the lock, the score or the record could be wrong, altered or unverifiable, or anything that exposes a secret, please report it privately through GitHub's private vulnerability reporting (the Security tab, "Report a vulnerability"), not in a public issue.

Everything else, such as a wrong number, a broken link or a question about the method, is welcome as an ordinary issue.
