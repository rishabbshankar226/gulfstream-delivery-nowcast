# Error analysis: the five largest held-out misses

The backtest reads a registry copy from 2026-10-19, which had months or years to fill in. It shows how well the registry tracks Gulfstream deliveries after the fact. Only the locked quarters test whether it counts them in time.

Ratio model under E1, the five held-out quarters with the largest absolute miss. Registry events are the airframes whose event date falls in the quarter's window.

## 2022Q1

The registry counted 38 airframes in the window against 25 GD deliveries, and the estimate of 40.7 came out 15.7 above GD's count (release accession 0000040533-22-000011).

No filing or call states why the registry count differed from GD's count in this quarter, so none is given here.
